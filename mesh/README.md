# Двумерная треугольная сетка

**Файлы:** `Mesh2D.h/.cpp`, `MeshTypes2D.h`, `BoundaryId.h`; генераторы — в [`generators`](generators/README.md).

Сетка состоит из узлов \(x_i\), треугольников \(K_e=(i,j,k)\) и граничных рёбер. `Mesh` хранит топологию и координаты; он не хранит температуры, скорости и давление как свойства геометрии.

## Топология и границы

У треугольника три ребра \((i,j),(j,k),(k,i)\). Для поиска общих рёбер пару индексов нормализуют как \((\min(i,j),\max(i,j))\). Ребро, принадлежащее ровно одному треугольнику, является граничным (для корректной двумерной многообразной сетки). `BoundaryId` связывает его с физическим условием.

Внешняя нормаль \(n\) должна вычисляться с учётом того, **какая сторона ребра является внутренностью элемента**, а не только порядка двух индексов. Для отверстий это особенно важно.

## Качество элементов

Площадь:

$$
|K|=\tfrac12 |(x_2-x_1)(y_3-y_1)-(y_2-y_1)(x_3-x_1)|.
$$

Площадь должна быть положительной, а треугольники не должны быть почти вырожденными. Узкие треугольники ухудшают обусловленность матриц и точность градиентов.

## Инварианты для текущей реализации

Индексы узлов должны соответствовать внутренней нумерации; ссылки из элементов и граничных рёбер — существовать; общие геометрические вершины должны иметь общие ID. При импорте VTK особенно важно не перепутать внешние номера с внутренними индексами.
