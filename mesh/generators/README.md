# Генерация сетки

**Файлы:** `MesherRectangle.h/.cpp`, `TriangularMesher2D.h/.cpp`.

Генератор переводит геометрическую область в набор узлов и треугольников. Для прямоугольника применяется регулярное разбиение по \(x\) и \(y\):

\[
x_i=x_0+iL/(n_x-1),\qquad y_j=y_0+jH/(n_y-1).\]

Каждая прямоугольная ячейка разбивается диагональю на два P1-треугольника. При \(n_x\times n_y\) узлах число элементов равно \(2(n_x-1)(n_y-1)\). Пример `61 × 21`: **1281 узел, 2400 треугольников**.

Граничные рёбра получают маркеры левой, правой, верхней и нижней сторон. Генератор должен создавать согласованную ориентацию треугольников и не дублировать узлы на общих рёбрах.

`TriangularMesher2D` следует рассматривать по фактическому коду как отдельную заготовку/компонент; не предполагайте наличие универсальной constrained-триангуляции произвольных областей. Сетка канала с отверстием в `mainHydro.cpp` **импортируется из VTK**, а не строится универсальным генератором.
