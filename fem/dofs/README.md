# Отображения степеней свободы (DOF)

**Файлы:** `P2DofMap.h/.cpp`, `TaylorHoodDofMap.h`.

Локальный элемент использует номера \(0\ldots5\), но глобальная система должна разделять общие DOF соседних треугольников. `P2DofMap` хранит исходные вершины и **один общий срединный узел на каждое уникальное ребро**. Ключ ребра нормализуется как `(min(a,b), max(a,b))`.

Для элемента локальный порядок P2: `[v0,v1,v2,m01,m12,m20]`. Общая середина ребра должна получать один и тот же индекс независимо от направления обхода элемента.

## Taylor–Hood

`TaylorHoodDofMap` создаёт для каждого P2-узла два DOF скорости и для каждого исходного P1-узла один DOF давления:

\[
N_u=2N_{P2},\qquad N_p=N_{P1},\qquad N=N_u+N_p.
\]

По коду локальные DOF имеют порядок **12 компонент скорости, затем 3 давления**; глобально скорость занимает начало вектора, давление — конец. Удобно обозначать

\[
U_i=i,\qquad V_i=N_{P2}+i,\qquad P_j=2N_{P2}+j.
\]

Именно такая **покомпонентная глобальная нумерация** реализована методами `U`, `V`, `P` в `TaylorHoodDofMap.h`. При этом локальный массив `ElementDofs` чередует `u_i,v_i` для шести узлов. Не путайте локальный порядок с глобальным.

**Проверки:** два соседних треугольника разделяют DOF вершины и середины общего ребра; индексы не выходят за \([0,N)\); локальный массив имеет длину 15; число давлений равно числу исходных вершин.
