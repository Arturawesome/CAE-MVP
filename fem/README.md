# Метод конечных элементов: общая схема

МКЭ заменяет непрерывное поле конечномерной аппроксимацией \(u_h(x)=\sum_i U_iN_i(x)\). После умножения уравнения на тестовую функцию, интегрирования по области и интегрирования по частям получается слабая форма, затем система \(KU=F\) либо смешанная система скорости–давления.

Этапы: **(1)** геометрия и сетка; **(2)** локальные базисные функции; **(3)** интегралы по элементам и границам; **(4)** отображение локальных DOF в глобальные; **(5)** разреженная сборка; **(6)** граничные условия; **(7)** решение.

- [`elements/README.md`](elements/README.md) — P1/P2 и квадратуры.
- [`dofs/README.md`](dofs/README.md) — глобальная нумерация и Taylor–Hood.
- [`systems/README.md`](systems/README.md) — разреженная линейная система.

Ключевое свойство: соседние элементы используют **одни и те же глобальные DOF** на общей вершине или ребре; именно это обеспечивает непрерывность \(C^0\)-аппроксимации.
