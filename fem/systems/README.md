# Разреженные линейные системы

**Файл:** `LinearSystem.h`.

`fem::LinearSystem` хранит \(K\) как `Eigen::SparseMatrix<double>`, а правую часть \(F\) как `Eigen::VectorXd`. МКЭ-матрица разрежена: функции формы взаимодействуют только внутри соседних элементов, поэтому большинство глобальных коэффициентов равны нулю.

## Сборка через триплеты

Каждый локальный коэффициент \(K^e_{ij}\) преобразуется в тройку `(global_i,global_j,value)`. `setFromTriplets` суммирует совпадающие позиции. При сборке нельзя перезаписывать вклад одного элемента вкладом другого.

## Граничные условия Дирихле

Для фиксированного \(u_j=g_j\) симметричное исключение требует: для свободных строк \(F_i\leftarrow F_i-K_{ij}g_j\), удалить столбец и строку \(j\), поставить \(K_{jj}=1\), \(F_j=g_j\). Так сохраняется симметрия исходной матрицы.

## Выбор решателя

- Теплопроводность с корректными ограничениями обычно даёт симметричную положительно определённую систему: подходят `SimplicialLDLT`/`SimplicialLLT`.
- Смешанная система Стокса имеет седловую блочную структуру и, как правило, **не** положительно определена: возможен `SparseLU`.
- При полностью заданной скорости давление в Стоксе может определяться с точностью до константы — требуется фиксация уровня давления либо другое условие, устраняющее неопределённость.

Проверяйте статус факторизации, решения, конечность результата и невязку \(\|KU-F\|\). Не путайте матрицу \(K\) с правой частью \(F\) в `solve(F)`.
