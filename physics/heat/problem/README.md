# Постановка задачи теплопроводности

**Файлы:** `Problem.h/.cpp`.

`HeatProblem` хранит сетку, коэффициент теплопроводности \(\lambda\), источник \(f(x,y,t)\) и набор условий на границах. Сигнатура источника допускает время, хотя текущая модель теплопроводности **стационарная**.

Типы условий (`HeatBoundaryCondition.h`):

- **Dirichlet:** \(T=T_D\), фиксируется значение узловой температуры.
- **Neumann:** задаётся нормальный поток; он входит в правую часть.
- **Robin:** конвективный теплообмен с внешней средой, \(-\lambda\partial_nT=\alpha(T-T_\infty)\), где \(\alpha\ge0\).

Границы задаются по `BoundaryId`; один и тот же геометрический узел может принадлежать двум сторонам. Если на нём встретились два условия Дирихле, значения должны совпадать.

**Физические единицы в SI:** \(T\) — K (или °C для разностей), \(\lambda\) — Вт/(м·К), \(f\) — Вт/м³ в 3D; в 2D-постановке предполагается единичная толщина либо согласованная редукция единиц.
