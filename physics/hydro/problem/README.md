# Постановка гидродинамической задачи

**Файлы:** `HydroProblem.h/.cpp`.

`HydroProblem` хранит \(\rho\), \(\mu\), колбэк объёмной силы \(\mathbf f(x,y,t)\), начальной скорости \(\mathbf u_0(x,y,t)\) и граничные условия. Передача `std::function` **по значению** и последующее перемещение при сохранении — подходящий вариант владения. Захваты лямбды по ссылке на локальные переменные, которые уничтожатся раньше решения, опасны.

## Типы граничных условий

В `HydroBoundaryCondition.h`:

| Тип | Передаваемое значение | Условие |
|---|---|---|
| `VelocityDirichlet` | векторная функция | \(\mathbf u=\mathbf g\) |
| `Traction` | векторная функция | \(\sigma n=\mathbf t\) |
| `NormalTraction` | скалярная функция | \(\sigma n=qn\) |

Нормаль к границе вычисляется по сетке в ассемблере, а не в `HydroProblem`. Внутреннее поле давления \(p\) остаётся неизвестной смешанной системы. При задании только скоростей может возникать неопределённость давления с точностью до константы.

## Проверки

\(\rho>0\), \(\mu>0\), конечные значения; непустые колбэки; согласованные значения Дирихле в углах; отсутствие несовместимых условий на одном маркере. Размерности SI: \(\rho\) кг/м³, \(\mu\) Па·с, \(p\) и traction Па, \(u\) м/с.
