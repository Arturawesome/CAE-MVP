# Нестационарная несжимаемая гидродинамика

**Файлы:** `HydroSolver.h/.cpp`, `HydroBoundaryCondition.h`; постановка — [`problem`](problem/README.md), сборка — [`assembly`](assembly/README.md).

## Уравнения

$$
\rho(\partial_t\mathbf u+(\mathbf u\cdot\nabla)\mathbf u)-\nabla\cdot(2\mu D(\mathbf u))+\nabla p=\mathbf f,
\qquad\nabla\cdot\mathbf u=0.
$$

$\rho$ — плотность, $\mu$ — динамическая вязкость, $\mathbf u$ — скорость, $p$ — давление. Для линейного Стокса конвективный член опускают; в текущем коде он **присутствует**, поэтому название «только Стокс» было бы неточным.

## Taylor–Hood P2/P1

Скорость $\mathbf u$ — квадратичная по каждому треугольнику, давление $p$ — линейное. На элементе 12 DOF скорости + 3 давления. Дискретная несжимаемость связывает эти переменные через матрицу дивергенции.

## Блочная система

При согласованном выборе знаков слабой формы:

$$
\begin{pmatrix}M/\Delta t+A+C(\mathbf u^n)&-B^T\\B&0\end{pmatrix}
\begin{pmatrix}\mathbf u^{n+1}\\p^{n+1}\end{pmatrix}
=
\begin{pmatrix}\mathbf f^{n+1}+(M/\Delta t)\mathbf u^n\\0\end{pmatrix}.
$$

Здесь $M$ — массовая, $A$ — вязкостная, $C$ — конвективная, $B$ — дивергенция. **Знаки блоков** должны соответствовать фактической реализации `BuildTimeSystem`, а не механически копироваться из другой книги.

## Временная схема

`HydroSolver` использует предыдущую скорость для массового члена и для построения конвекции, т.е. конвекция линеаризуется по предыдущему шагу. Это не полноценный нелинейный Ньютоновский решатель; при больших Reynolds или крупном $\Delta t$ необходимы проверки устойчивости и сходимости.

## Граничные условия

- `VelocityDirichlet`: задана скорость, включая срединные P2-узлы.
- `Traction`: задан полный вектор $\sigma n$.
- `NormalTraction`: задан скаляр $q$, преобразуемый в $\sigma n=qn$ (положительный $q$ — усилие по внешней нормали).

$\sigma=-pI+2\mu D(\mathbf u)$. **Важное соглашение фактического кода:** `HydroAssembler2D::MakeLocalTraction` использует `traction = tn * normal` **без минуса**. Поэтому при моделировании внешнего давления `p_ext > 0` нужно передавать `tn = -p_ext`. `NormalTraction` не является прямым условием $p=q$ для внутренних P1-узлов давления**. Подробности в `assembly/README.md`.

## Контроль расчёта

Проверяйте $\nabla\cdot\mathbf u$, невязку, баланс массы, корректность нормалей и граничных меток, шаг по времени и независимость решения от сгущения сетки. Для потока через канал используйте $Re=\rho U H/\mu$. В `mainHydro.cpp` используется импортированная сетка канала с препятствием и VTK-серия кадров.
