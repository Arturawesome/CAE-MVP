# Физические постановки

Каталог разделяет физику и общий численный каркас МКЭ. `heat` реализует скалярную задачу второго порядка, `hydro` — связанную векторно-скалярную задачу с условием несжимаемости.

Общие части — сетка, элементы, глобальная нумерация, разреженные матрицы. Разные части — слабые формы, граничные условия, временные схемы и свойства глобальной системы.

- [Теплопроводность](heat/README.md)
- [Гидродинамика](hydro/README.md)

Не следует объединять обе физики в один универсальный `Assembler`: это усложнит архитектуру MVP без существенной пользы.
