# Ввод/вывод и ParaView

**Файлы:** `VTKReader.h/.cpp`, `VTKWriter.h`, `VTKHydroWriter.h/.cpp`, `VTKSeriesWriter.h/.cpp`, `STLWriter.h`.

## VTK

VTK хранит координаты узлов, связность ячеек и поля. `VTKReader::ReadUstructuredGrid` используется для импорта двумерной треугольной сетки из `.vtk`; при чтении нужно проверять поддерживаемые типы ячеек и согласованность индексов. `VTKWriter` экспортирует тепловое поле, `VTKHydroWriter` — гидродинамические поля. Для P2-скорости и P1-давления важно корректно интерполировать/сопоставлять данные с выводимой сеткой.

## Временные ряды

`VTKSeriesWriter` создаёт `.vtk.series` — JSON-индекс кадров с временными метками. В ParaView открывайте файл серии для анимации, а отдельный `.vtk` — для одного шага.

## Практический запуск

```bash
cmake -S . -B build
cmake --build build -j
./build/cae_heat
./build/cae_hydro
```

Открыть в ParaView: `File → Open → Apply`, выбрать поле в меню Coloring, при необходимости `Rescale to Data Range`. Для скорости используйте `Glyph`, `Stream Tracer` или `Calculator` (модуль скорости); для давления — окраску скалярного поля.

**Относительные пути** отсчитываются от текущего рабочего каталога. `mainHydro.cpp` ожидает входной файл `channel_hole_L006_under800.vtk` в рабочем каталоге.

## STL

STL содержит треугольную поверхность, но **не** граничные условия, поля и полноценную CAD-топологию. Для 2D-MVP нельзя считать произвольный STL готовой плоской конечно-элементной сеткой. Не путайте экспорт геометрии с импортом объёмной расчётной сетки.
