# Сборка теплопроводности и граничных условий

**Файлы:** `Assembler2D.h/.cpp`, `BoundaryAssembler2D.h/.cpp`.

## Объёмная матрица

Для P1-треугольника $K_e$:

$$
K^e_{ij}=\lambda\int_{K_e}\nabla N_i\cdot\nabla N_j\,d\Omega
=\lambda|K_e|\nabla N_i\cdot\nabla N_j.
$$

Локальная матрица **3×3**. Элементные коэффициенты помещаются в `Eigen::Triplet`, одинаковые глобальные индексы суммируются. Источник интегрируется в текущей реализации с выбранной аппроксимацией по элементу; для непостоянного источника точность интегрирования следует проверять отдельно.

## Neumann

Если $g=\lambda\partial_nT$, то $F_i^\Gamma=\int_\Gamma gN_i\,d\Gamma$. Для постоянного $g$ на прямом P1-ребре длины $\ell$ оба конца получают $g\ell/2$.

**Внимание к знаку:** физический выходящий поток $q_n=-\lambda\partial_nT$ даёт $F_i^\Gamma=-\int_\Gamma q_nN_i\,d\Gamma$. Текущий код `AddNeumann` добавляет переданный параметр с **плюсом**: интерпретируйте его как $g=\lambda\partial_nT$, либо измените знак при выборе другого API.

## Robin

Для $-\lambda\partial_nT=\alpha(T-T_\infty)$ граничный вклад переносится в левую часть:

$$
K^\Gamma=\frac{\alpha\ell}{6}\begin{pmatrix}2&1\\1&2\end{pmatrix},\qquad
F^\Gamma=\frac{\alpha T_\infty\ell}{2}\begin{pmatrix}1\\1\end{pmatrix}.
$$

Код собирает отдельные sparse-триплеты и добавляет граничную матрицу к объёмной.

## Dirichlet

Сначала собрать **все** фиксированные узлы, проверить совпадение значений в углах, затем однократно выполнить исключение: $F_i\leftarrow F_i-K_{ij}T_j$, удалить строку/столбец фиксированного узла, поставить диагональную единицу и $F_j=T_j$.

**Правильный порядок:** объёмная сборка → Neumann/Robin → Dirichlet → решение. Если применить Дирихле раньше Робина, граничные добавки могут нарушить закрепление.
